# Research agenda deck

`research-agenda.html` is a self-contained 26-slide presentation of the Proof-of-Control
research roadmap, built on the Advanced AI Society deck template (1920×1080, off-white ground,
Jost / Atkinson Hyperlegible Next / Inter, cinnabar section dividers cited from
`assets/shapes/dividers.json`). Fonts are embedded, so it presents offline.

**Present:** open the file in a browser. ← → or Space to move, Home / End, F for fullscreen,
click the right or left half of the slide. `#12` in the URL jumps to a slide.
**PDF:** ⌘P prints one slide per page at 1920×1080.

**Edit:** change `src/research-agenda.src.html`, then run `python3 src/build.py`
(needs `fonttools`, and the brand fonts at `~/Desktop/ClaudeDesign/fonts`).
