# poc-audit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A CLI that reads a Proof-of-Control evidence record and reports, field by field, what actually backs each claim — by reusing `parallax`, `transit` and `occultation` as libraries rather than reimplementing their findings.

**Architecture:** A fourth `RESIDUAL` layer on top of the standard's existing three-layer `validate.py`. A registry maps each required field of the record to a `FieldAuditor`; each auditor is handed the whole record plus an optional `Context` and returns one `Finding` carrying one of five verdicts. Auditors cannot observe one another, so there is no ordering dependency.

**Tech Stack:** Rust 2021 (edition and toolchain floor matched to the dependencies), `clap` v4 derive, `serde`/`serde_json`, and git dependencies on the three research crates.

**Spec:** [`docs/superpowers/specs/2026-08-09-poc-audit-design.md`](../specs/2026-08-09-poc-audit-design.md)

## Global Constraints

- **Rust edition 2021, `rust-version = "1.90"`** — matches `occultation`, the highest floor of the three dependencies.
- **`#![forbid(unsafe_code)]`** in `src/lib.rs`. All three dependencies hold this line.
- **Dependencies are pinned by `rev` to a commit on each repo's default branch.** No tags exist in any of the three repositories as of 2026-08-09, so `tag = ` is not available. Pinned revisions:
  - `parallax` — `efd1b64`
  - `transit` — `3e10e13`
  - `occultation` — `d1cc941`
  - A `rev` pointing at an unpushed commit resolves for nobody else. Only use commits present on `origin`.
- **Every test runs offline.** No network, no credentials, no third-party host. Fixtures are committed or come from the dependencies' own committed examples.
- **This tool fails loud.** It is not in a request path. A misconfigured input is an error, never a silent downgrade to `UNCHECKED`. This is deliberately the opposite of `occultation`'s fail-open rule — do not import that reflex here.
- **No signing, no key material, no `--emit`.** The tool reads records and reports.
- **The report never prints an aggregate pass/fail and never the word "compliant".**
- **Exit codes:** `0` clean · `1` at least one `DIVERGES` or `CANNOT HOLD` (or any `UNCHECKED` under `--require-checked`) · `2` bad input, unreadable optional input, or a failed auditor.

```rust
/// The Proof-of-Control Evidence Token, as far as this tool reads it.
///
/// `deny_unknown_fields` is deliberately NOT set: the schema allows additional
/// properties on `poc_claims`, and refusing them here would reject records the
/// standard considers valid.
#[derive(Debug, Clone, Deserialize)]
pub struct Record {
    pub iss: String,
    pub iat: i64,
    pub nonce: String,
    pub eat_profile: String,
    pub poc_claims: PocClaims,
    pub submods: Submods,
    #[serde(default)]
    pub signature: Option<String>,
}

#[derive(Debug, Clone, Deserialize)]
pub struct PocClaims {
    pub agent_id: String,
    pub initiating_user: String,
    pub agbom_digest: String,
    pub interception_point: String,
    pub step_index: u64,
    pub chain_head: String,
    pub merkle_root: String,
    pub tree_size: u64,
    pub policy_bundle_hash: String,
    pub target_resource: String,
    pub canonical_snapshot_hash: String,
    pub path_summary_hash: String,
    pub verdict: String,
    pub alg: String,
    #[serde(default)]
    pub reason: Option<String>,
}

#[derive(Debug, Clone, Deserialize)]
pub struct Submods {
    pub attestation: Attestation,
}

#[derive(Debug, Clone, Deserialize)]
pub struct Attestation {
    pub platform: String,
    pub measurement: String,
    /// Optional in the schema. That it is optional is `parallax`'s finding.
    #[serde(default)]
    pub reference_values_uri: Option<String>,
}

#[derive(Debug, thiserror::Error)]
pub enum RecordError {
    #[error("{0}\n\nThis tool is the fourth layer and assumes the first three passed. Run ov-poc-standard/schema/validate.py on this record first.")]
    Malformed(String),
}

impl Record {
    pub fn parse(src: &str) -> Result<Self, RecordError> {
        serde_json::from_str(src).map_err(|e| RecordError::Malformed(e.to_string()))
    }
}
```

```rust
#![forbid(unsafe_code)]

use clap::Parser;
use std::path::PathBuf;
use std::process::ExitCode;

#[derive(Parser)]
#[command(name = "poc-audit", about = "What actually backs each claim in a Proof-of-Control evidence record")]
struct Cli {
    /// The evidence record to audit.
    record: PathBuf,
}

fn main() -> ExitCode {
    let cli = Cli::parse();
    let src = match std::fs::read_to_string(&cli.record) {
        Ok(s) => s,
        Err(e) => {
            eprintln!("error: cannot read {}: {e}", cli.record.display());
            return ExitCode::from(2);
        }
    };
    match poc_audit::record::Record::parse(&src) {
        Ok(_) => ExitCode::SUCCESS,
        Err(e) => {
            eprintln!("error: {e}");
            ExitCode::from(2)
        }
    }
}
```

```rust
use std::collections::BTreeSet;

/// The schema's `required` arrays are the source of truth for the report's
/// rows. When the standard adds a required field, this fails rather than the
/// report silently narrowing.
#[test]
fn every_required_field_is_accounted_for() {
    let schema: serde_json::Value = serde_json::from_str(include_str!(
        "../schema/poc-evidence.schema.json"
    ))
    .expect("vendored schema is json");

    let mut required: BTreeSet<String> = BTreeSet::new();
    for r in schema["required"].as_array().expect("top-level required") {
        required.insert(r.as_str().expect("required entry is a string").to_string());
    }
    for r in schema["$defs"]["pocClaims"]["required"].as_array().expect("pocClaims required") {
        required.insert(format!("poc_claims.{}", r.as_str().expect("string")));
    }
    for r in schema["$defs"]["attestation"]["required"].as_array().expect("attestation required") {
        required.insert(format!("submods.attestation.{}", r.as_str().expect("string")));
    }
    assert!(required.len() > 10, "the schema parse found almost nothing: {required:?}");

    let accounted: BTreeSet<String> = poc_audit::registry::ACCOUNTED
        .iter()
        .map(|(f, _)| (*f).to_string())
        .collect();

    // Every Audited field must have an auditor claiming it. `run` panics on a
    // mismatch by design, and until this test existed that panic was invisible:
    // no test ran the binary, so a registry claiming auditors it did not have
    // shipped a tool that died on its first real record.
    let claimed: BTreeSet<&str> = poc_audit::registry::auditors()
        .iter()
        .map(|a| a.field())
        .collect();
    for (field, coverage) in poc_audit::registry::ACCOUNTED {
        if matches!(coverage, poc_audit::registry::Coverage::Audited) {
            assert!(
                claimed.contains(field),
                "{field} is marked Audited but no auditor claims it; \
                 registry::run would panic on every record"
            );
        }
    }

    let unaccounted: Vec<&String> = required.difference(&accounted).collect();
    assert!(
        unaccounted.is_empty(),
        "the schema requires fields that ACCOUNTED does not list: {unaccounted:?}\n\
         Add each to src/registry.rs, either with an auditor or as \
         Coverage::Unaudited with a reason."
    );

    let stale: Vec<&String> = accounted.difference(&required).collect();
    assert!(
        stale.is_empty(),
        "ACCOUNTED lists fields the schema does not require: {stale:?}"
    );
}
```

`src/verdict.rs`:

```rust
use std::path::PathBuf;

/// A non-empty attribution. `Verdict::Established` cannot be constructed
/// without one, which makes the presence of an attribution structural; the
/// non-emptiness is enforced here and pinned by test.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct BackedBy(String);

impl BackedBy {
    pub fn new(s: impl Into<String>) -> Option<Self> {
        let s = s.into();
        if s.trim().is_empty() { None } else { Some(Self(s)) }
    }
    pub fn as_str(&self) -> &str { &self.0 }
}

/// Why a field was not checked. The variants differ in consequence, not only
/// in wording: `AuditorFailed` sets exit 2, the others do not. Without that
/// split a panicking auditor yields `UNCHECKED`, `UNCHECKED` does not fail,
/// and a crash reads as a pass.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Why {
    /// Carries the flag that would deepen this row.
    MissingInput(&'static str),
    NoAuditor,
    AuditorFailed(String),
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Verdict {
    Established(BackedBy),
    Asserted,
    Diverges,
    CannotHold,
    Unchecked(Why),
}

impl Verdict {
    pub fn label(&self) -> &'static str {
        match self {
            Verdict::Established(_) => "ESTABLISHED",
            Verdict::Asserted => "ASSERTED",
            Verdict::Diverges => "DIVERGES",
            Verdict::CannotHold => "CANNOT HOLD",
            Verdict::Unchecked(_) => "UNCHECKED",
        }
    }
    pub fn is_failure(&self) -> bool {
        matches!(self, Verdict::Diverges | Verdict::CannotHold)
    }
    pub fn is_unchecked(&self) -> bool { matches!(self, Verdict::Unchecked(_)) }
    pub fn auditor_failed(&self) -> bool {
        matches!(self, Verdict::Unchecked(Why::AuditorFailed(_)))
    }
}

/// One principal that must be honest for a finding to mean what it says.
/// Mirrors `parallax::trust::Assumption` without depending on it, so that
/// findings from all three tools can carry the same drill-down shape.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Residual {
    pub principal: String,
    pub capability: String,
    pub detect: String,
    pub impact: String,
}

#[derive(Debug, Clone)]
pub struct Finding {
    pub field: &'static str,
    pub verdict: Verdict,
    /// One line, shown beside the verdict.
    pub reason: String,
    /// Shown by `--explain`. Empty is normal.
    pub residual: Vec<Residual>,
}

/// Which identity profile the deployment declares.
///
/// C5.1.1 requires a persistent agent identifier. That requirement is
/// SATISFIABLE under `Standard` and unsatisfiable under `Unlinkable`, so the
/// same record earns opposite verdicts depending on which is in force —
/// and nothing in a record says which. It is therefore an input, never an
/// inference: guessing it from the shape of an identifier would manufacture
/// the false finding this tool exists to avoid.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, clap::ValueEnum)]
pub enum Profile {
    /// A persistent agent identifier is expected. C5.1.1 can be met.
    #[default]
    Standard,
    /// No persistent agent identifier exists. C5.1.1 must be suspended.
    Unlinkable,
}

/// The optional inputs. Each auditor names the flag it needs in
/// `Why::MissingInput` when its own input is absent.
#[derive(Debug, Default, Clone)]
pub struct Context {
    pub deployment: Option<PathBuf>,
    pub payload: Option<String>,
    pub fleet: Option<PathBuf>,
    /// Defaults to `Standard`. See `Profile`.
    pub profile: Profile,
}
```

```rust
use crate::field::{chain::Chain, FieldAuditor};
use crate::record::Record;
use crate::verdict::{Context, Finding, Verdict, Why};

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Coverage {
    /// An auditor in `auditors()` claims this field.
    Audited,
    /// Deliberately not audited. The string is shown as the row's reason.
    Unaudited(&'static str),
}

/// Every field the schema requires, and how it is covered.
///
/// This list is the acknowledgement gate. A field added upstream fails
/// `every_required_field_is_accounted_for` until someone decides, explicitly,
/// whether it gets an auditor or a reason.
pub const ACCOUNTED: &[(&str, Coverage)] = &[
    ("iss",         Coverage::Unaudited("issuer identity is out of scope")),
    ("iat",         Coverage::Unaudited("issuance time is out of scope")),
    ("nonce",       Coverage::Unaudited("freshness against a challenge is out of scope")),
    ("eat_profile", Coverage::Unaudited("profile identity is checked by validate.py")),
    ("poc_claims",  Coverage::Unaudited("audited through its individual claims")),
    ("submods",     Coverage::Unaudited("audited through submods.attestation.*")),

    // Flipped to Coverage::Audited by the task that adds the auditor. A field
    // marked Audited with no auditor claiming it panics `run` by design, so
    // these two facts must move together, in one commit, every time.
    ("poc_claims.agent_id",                Coverage::Unaudited("identity auditor arrives in Task 5")),
    ("poc_claims.initiating_user",         Coverage::Unaudited("identity auditor arrives in Task 5")),
    ("poc_claims.canonical_snapshot_hash", Coverage::Unaudited("canonical auditor arrives in Task 4")),

    ("poc_claims.chain_head",              Coverage::Audited),
    ("poc_claims.merkle_root",             Coverage::Audited),
    ("poc_claims.step_index",              Coverage::Audited),

    ("poc_claims.agbom_digest",       Coverage::Unaudited("no AgBOM tooling exists; see P10")),
    ("poc_claims.interception_point", Coverage::Unaudited("enumerated value, checked by validate.py")),
    ("poc_claims.tree_size",          Coverage::Unaudited("consistency with step_index is validate.py's semantic layer")),
    ("poc_claims.policy_bundle_hash", Coverage::Unaudited("no policy-bundle tooling exists")),
    ("poc_claims.target_resource",    Coverage::Unaudited("free text; nothing to check it against")),
    ("poc_claims.path_summary_hash",  Coverage::Unaudited("bounded path summaries are P04, unbuilt")),
    ("poc_claims.verdict",            Coverage::Unaudited("enumerated value, checked by validate.py")),
    ("poc_claims.alg",                Coverage::Unaudited("signature checking is validate.py's semantic layer")),

    ("submods.attestation.platform",    Coverage::Unaudited("attestation auditor arrives in Task 3")),
    ("submods.attestation.measurement", Coverage::Unaudited("attestation auditor arrives in Task 3")),

/// Every auditor. Later tasks push onto this list.
pub fn auditors() -> Vec<Box<dyn FieldAuditor>> {

/// Run every accounted field and return one `Finding` each, in `ACCOUNTED`
/// order so output is stable.
///
/// An auditor that panics becomes `AuditorFailed` rather than taking the other
/// findings down with it — a third-party parser over supplied bytes is exactly
/// where a panic would originate. It must never be mistaken for a clean row,
/// which is why `AuditorFailed` sets exit 2.
pub fn run(rec: &Record, ctx: &Context) -> Vec<Finding> {
    let auditors = auditors();
    ACCOUNTED
        .iter()
        .map(|(field, coverage)| match coverage {
            Coverage::Unaudited(reason) => Finding {
                field,
                verdict: Verdict::Unchecked(Why::NoAuditor),
                reason: (*reason).to_string(),
                residual: Vec::new(),
            },
            Coverage::Audited => {
                let a = auditors
                    .iter()
                    .find(|a| a.field() == *field)
                    .unwrap_or_else(|| panic!(
                        "{field} is marked Audited but no auditor claims it"
                    ));
                std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| a.audit(rec, ctx)))
                    .unwrap_or_else(|_| Finding {
                        field,
                        verdict: Verdict::Unchecked(Why::AuditorFailed(
                            format!("the auditor for {field} panicked"),
                        )),
                        reason: format!("the auditor for {field} panicked"),
                        residual: Vec::new(),
                    })
            }
        })
        .collect()
}
```

```rust
use crate::verdict::{Finding, Why};

pub fn render_table(findings: &[Finding]) -> String {
    let width = findings.iter().map(|f| f.field.len()).max().unwrap_or(0).max(5);
    let mut out = format!("{:<width$}  {:<12}  {}\n", "FIELD", "VERDICT", "WHY", width = width);
    for f in findings {
        out.push_str(&format!(
            "{:<width$}  {:<12}  {}\n",
            f.field,
            f.verdict.label(),
            f.reason,
            width = width
        ));
    }
    out.push_str(
        "\nNo aggregate verdict is printed. Each row stands alone; see the exit code.\n",
    );
    out
}

/// `0` clean · `1` a failure or, under `--require-checked`, an unchecked row ·
/// `2` an auditor failed.
pub fn exit_code(findings: &[Finding], require_checked: bool) -> u8 {
    if findings.iter().any(|f| f.verdict.auditor_failed()) {
        return 2;
    }
    if findings.iter().any(|f| f.verdict.is_failure()) {
        return 1;
    }
    if require_checked && findings.iter().any(|f| f.verdict.is_unchecked()) {
        return 1;
    }
    0
}
```

```rust
use super::FieldAuditor;
use crate::record::Record;
use crate::verdict::{BackedBy, Context, Finding, Residual, Verdict, Why};

/// Audits `submods.attestation`. One instance per field path, because the two
/// required sub-fields fail differently: `platform` can be structurally
/// unsupportable, `measurement` can be present but compared to nothing.
pub struct AttestationField(pub &'static str);

impl AttestationField {
    fn platform_finding(&self, rec: &Record) -> Finding {
        if rec.submods.attestation.platform == "SOFTWARE" {
            return Finding {
                field: self.0,
                verdict: Verdict::CannotHold,
                reason: "platform is SOFTWARE: no hardware isolation, so this \
                         evidence cannot support a Tier 3 or Tier 4 claim"
                    .into(),
                residual: Vec::new(),
            };
        }
        Finding {
            field: self.0,
            verdict: Verdict::Asserted,
            reason: format!(
                "platform is {}; the record asserts it and nothing here re-verifies the quote",
                rec.submods.attestation.platform
            ),
            residual: Vec::new(),
        }
    }

    fn measurement_finding(&self, rec: &Record, ctx: &Context) -> Finding {
        if rec.submods.attestation.reference_values_uri.is_none() {
            return Finding {
                field: self.0,
                verdict: Verdict::Asserted,
                reason: "reference_values_uri is absent, so the measurement was \
                         compared to nothing: this attests that some code ran in a \
                         genuine trust domain, not that it is your code"
                    .into(),
                residual: Vec::new(),
            };
        }
        let Some(path) = ctx.deployment.as_ref() else {
            return Finding {
                field: self.0,
                verdict: Verdict::Unchecked(Why::MissingInput("--deployment")),
                reason: "reference values are named, but who operates them is unknown".into(),
                residual: Vec::new(),
            };
        };
        // Loading errors are handled at Context construction, so a failure here
        // is a genuine solver failure rather than a bad path.
        match parallax::deployment::Deployment::load(path)
            .map_err(|e| e.to_string())
            .and_then(|d| parallax::solve::solve(&d).map_err(|e| e.to_string()))
        {
            Ok(set) => Finding {
                field: self.0,
                verdict: Verdict::Established(
                    BackedBy::new("parallax::solve").expect("non-empty literal"),
                ),
                reason: format!(
                    "reference values are named and the deployment solves; \
                     {} principals must be honest",
                    set.0.len()
                ),
                residual: set
                    .0
                    .iter()
                    .map(|a| Residual {
                        principal: a.principal.clone(),
                        capability: a.capability.clone(),
                        detect: format!("{:?}", a.latency),
                        impact: format!("{:?}", a.impact),
                    })
                    .collect(),
            },
            Err(e) => Finding {
                field: self.0,
                verdict: Verdict::Unchecked(Why::AuditorFailed(e.clone())),
                reason: format!("parallax could not solve the deployment: {e}"),
                residual: Vec::new(),
            },
        }
    }
}

impl FieldAuditor for AttestationField {
    fn field(&self) -> &'static str { self.0 }
    fn audit(&self, rec: &Record, ctx: &Context) -> Finding {
        if self.0.ends_with(".platform") {
            self.platform_finding(rec)
        } else {
            self.measurement_finding(rec, ctx)
        }
    }
}
```

```rust
use super::FieldAuditor;
use crate::record::Record;
use crate::verdict::{Context, Finding, Residual, Verdict, Why};

/// Audits `poc_claims.canonical_snapshot_hash`.
///
/// The record carries one digest. transit's finding is that two parties can
/// compute different digests over the same wire bytes, so one field name hides
/// a divergence. This runs the payload through every decoder model available
/// and reports whether they agree about what it *means*.
pub struct Canonical;

const FIELD: &str = "poc_claims.canonical_snapshot_hash";

/// Takes the list rather than fetching it, so a test can supply a synthetic
/// one. Fetching it internally makes this note — the entire host-dependence
/// honesty of this auditor — unverifiable on any machine that happens to have
/// every runtime installed, which is precisely the machine where it silently
/// does nothing.
/// Occurrences of the note's name in real code, ignoring comment lines.
///
/// A raw `matches(..).count()` over the source is satisfied by a comment, so
/// the guard that uses it can be defeated by the same edit that breaks what it
/// guards. Borrowed from the sibling `occultation` crate, whose formatter ban
/// strips comment lines for exactly this reason.
#[cfg(test)]
fn count_real_calls(src: &str) -> usize {
    src.lines()
        .filter(|l| !l.trim_start().starts_with("//"))
        .map(|l| l.matches("missing_note(").count())
        .sum()
}

fn missing_note(missing: &[transit::external::Missing]) -> String {
    if missing.is_empty() {
        String::new()
    } else {
        let ids: Vec<&str> = missing.iter().map(|m| m.id).collect();
        format!(
            " (weaker result: {} decoder runtimes missing on this host: {})",
            ids.len(),
            ids.join(", ")
        )
    }
}

impl FieldAuditor for Canonical {
    fn field(&self) -> &'static str { FIELD }

    fn audit(&self, _rec: &Record, ctx: &Context) -> Finding {
        let Some(payload) = ctx.payload.as_ref() else {
            return Finding {
                field: FIELD,
                verdict: Verdict::Unchecked(Why::MissingInput("--payload")),
                reason: "the record carries one digest; supply --payload to find out \
                         whether both sides compute it the same way"
                    .into(),
                residual: Vec::new(),
            };
        };
```

```rust
use super::FieldAuditor;
use crate::record::Record;
use crate::verdict::{Context, Finding, Residual, Verdict, Why};

/// Audits `poc_claims.agent_id` and `poc_claims.initiating_user`.
///
/// occultation's finding is not that these fields are wrong but that C5.1.1
/// requires both and an unlinkable profile cannot supply either. That is a
/// requirement a profile must suspend, not one better engineering satisfies.
pub struct Identity(pub &'static str);

impl Identity {
    fn value<'a>(&self, rec: &'a Record) -> &'a str {
        if self.0.ends_with("agent_id") {
            &rec.poc_claims.agent_id
        } else {
            &rec.poc_claims.initiating_user
        }
    }
}

impl FieldAuditor for Identity {
    fn field(&self) -> &'static str { self.0 }

    fn audit(&self, rec: &Record, ctx: &Context) -> Finding {
        let value = self.value(rec);
        if value.trim().is_empty() {
            return Finding {
                field: self.0,
                verdict: Verdict::Unchecked(Why::NoAuditor),
                reason: "the field is empty; there is no identifier to assess".into(),
                residual: Vec::new(),
            };
        }

        // The same identifier earns opposite verdicts under the two profiles,
        // and the record cannot say which is in force. Under Standard this
        // field is SATISFIED; reporting a failure would be a false finding on
        // every conformant record.
        let (verdict, mut reason) = match ctx.profile {
            Profile::Standard => (
                Verdict::Established(
                    BackedBy::new("the record carries a persistent identifier")
                        .expect("non-empty literal"),
                ),
                format!(
                    "'{value}' is a persistent identifier, so C5.1.1 is satisfied. \
                     The cost is that every action carrying it is linkable to one \
                     subject — which is precisely what an unlinkable profile \
                     cannot provide"
                ),
            ),
            Profile::Unlinkable => (
                Verdict::CannotHold,
                format!(
                    "an unlinkable profile is declared, and C5.1.1 requires a \
                     persistent identifier. '{value}' is one, so either the \
                     profile is not in force or the requirement must be \
                     suspended. It cannot be satisfied"
                ),
            ),
        };
        let mut residual = Vec::new();

        if let Some(path) = ctx.fleet.as_ref() {
            match occultation::anonymity::Fleet::load(path)
                .and_then(|f| occultation::anonymity::partition(&f))
            {
                Ok(r) => {
                    reason.push_str(&format!(
                        ". Against the supplied fleet: {} hosts, smallest anonymity set {}, \
                         effective set {:.1}, {} singletons",
                        r.fleet_size, r.min_set, r.effective_set, r.singletons
                    ));
                    residual.push(Residual {
                        principal: "the relying party".into(),
                        capability: format!(
                            "distinguishes this agent among {} in the smallest set",
                            r.min_set
                        ),
                        detect: "never".into(),
                        impact: "Privacy".into(),
                    });
                }
                Err(e) => {
                    return Finding {
                        field: self.0,
                        verdict: Verdict::Unchecked(Why::AuditorFailed(e.to_string())),
                        reason: format!("occultation could not partition the fleet: {e}"),
                        residual: Vec::new(),
                    }
                }
            }
        } else {
            reason.push_str(". Supply --fleet for the anonymity-set size");
        }

        Finding { field: self.0, verdict, reason, residual }
    }
}
```

```rust
use crate::verdict::Residual;

/// The drill-down behind one finding: who must be honest, what they could do,
/// and how long before you would know. This is parallax's model used as the
/// detail view rather than the headline — "five principals, four undetectable"
/// does not tell a developer whether they passed.
pub fn render_explain(findings: &[Finding], field: &str) -> Result<String, String> {
    let f = findings
        .iter()
        .find(|f| f.field == field)
        .ok_or_else(|| {
            let known: Vec<&str> = findings.iter().map(|f| f.field).collect();
            format!("no such field: {field}\nknown fields:\n  {}", known.join("\n  "))
        })?;

    let mut out = format!("{}  {}\n{}\n\n", f.field, f.verdict.label(), f.reason);
    if f.residual.is_empty() {
        out.push_str("There is no residual trust set behind this finding.\n");
        return Ok(out);
    }
    out.push_str("Who must be honest for this to mean what it says:\n\n");
    let w = f.residual.iter().map(|r: &Residual| r.principal.len()).max().unwrap_or(0);
    for r in &f.residual {
        out.push_str(&format!(
            "  {:<w$}  {}  detect: {}  impact: {}\n",
            r.principal, r.capability, r.detect, r.impact, w = w
        ));
    }
    Ok(out)
}
```

```rust
use crate::record::Record;

/// The C8 tier, printed because a conformance process asks for it and
/// subordinated because P01 holds the ladder is wrong as written. Attribution
/// is not decoration: it is the difference between reporting the standard's
/// framing and endorsing it.
pub fn tier_line(rec: &Record) -> String {
    let tier = match rec.submods.attestation.platform.as_str() {
        "SOFTWARE" => 1,
        _ if rec.submods.attestation.reference_values_uri.is_some() => 3,
        _ => 2,
    };
    let why = match tier {
        1 => "platform is SOFTWARE: no hardware isolation",
        2 => "no reference values, so code identity is unestablished",
        _ => "hardware platform with named reference values",
    };
    format!("per C8 (see P01: the ladder is contested): Tier {tier} — {why}")
}
```

````markdown
# poc-audit

The Proof-of-Control standard ships a validator with three layers. This is the
fourth.

```
validate.py                     poc-audit
  1 STRUCTURE   the JSON Schema      ─┐
  2 CANONICAL   RFC 8785 + profile    ├─ assumed to have passed
  3 SEMANTIC    tier / signature      ─┘
                                          4 RESIDUAL
                                            what the fields do not tell you
```

Layers 1–3 ask whether a record is well-formed and internally consistent.
This one asks whether it means what you think.

```console
$ poc-audit evidence.json
FIELD                              VERDICT      WHY
submods.attestation.measurement    ASSERTED     reference_values_uri is absent, so the
                                                measurement was compared to nothing
poc_claims.agent_id                ESTABLISHED  a persistent identifier, so C5.1.1 is
                                                satisfied; every action carrying it is linkable
poc_claims.canonical_snapshot_hash UNCHECKED    supply --payload to find out whether both
                                                sides compute it the same way
poc_claims.chain_head              UNCHECKED    no auditor: chain continuity is unimplemented
```

Each row is answered by a different research tool: `parallax` for the
attestation, `transit` for the canonical form, `occultation` for identity.
They are reused as libraries, not reimplemented.

## The five verdicts

| verdict | means |
| --- | --- |
| `ESTABLISHED` | something outside the record checked it, and it holds |
| `ASSERTED` | we looked, and found nothing behind it |
| `DIVERGES` | two parties who must agree produce different values |
| `CANNOT HOLD` | structurally unsatisfiable here, not merely unverified |
| `UNCHECKED` | we did not look — no auditor, or its input was missing |

**`ASSERTED` is not `UNCHECKED`.** "I checked and there is nothing behind this"
is a different statement from "I did not check." Collapsing them is how a
report ends up implying coverage it does not have.

## Deepening a report

The record alone always produces a report. Each optional input upgrades some
`UNCHECKED` rows to real verdicts, and each is one of the three tools' own
existing formats — there is no fourth config language.

| flag | deepens | format |
| --- | --- | --- |
| `--deployment` | `submods.attestation.*` | a `parallax` deployment |
| `--payload` | `poc_claims.canonical_snapshot_hash` | the raw request bytes |
| `--fleet` | `poc_claims.agent_id` | an `occultation` fleet |
| `--profile` | `poc_claims.agent_id` | `standard` (default) or `unlinkable` |

`--profile` is the one input that can *reverse* a verdict rather than deepen
it. A persistent `agent_id` satisfies C5.1.1 under `standard` and cannot hold
under `unlinkable`, and nothing in a record says which is in force — so the
tool asks rather than guessing. Guessing it from the shape of an identifier
would manufacture exactly the false finding this tool exists to avoid.

`--explain <field>` prints the residual trust set behind one finding: who must
be honest, what they could do, and how long before you would know.

## Exit codes

| code | condition |
| :--: | --- |
| `0` | nothing `DIVERGES` or `CANNOT HOLD` |
| `1` | at least one did, or any `UNCHECKED` under `--require-checked` |
| `2` | bad input, an unreadable optional input, or an auditor that failed |

`--require-checked` is the CI gate for "no unaudited fields". It changes only
the exit code; the report is byte-identical.

## What this does not do

- **No signing, no keys, no `--emit`.** It reads records and reports on them.
  Signing a "you passed" token is the overclaim this whole programme attacks.
- **No aggregate pass/fail, and never the word "compliant".** A single summary
  word is how a deployment claims a tier it has not earned. The C8 tier is
  printed, attributed to the standard rather than endorsed — see P01, which
  holds the ladder is wrong as written.
- **No runtime composition.** Chaining the three tools' proxies in one request
  path is a separate, unbuilt design: two of them refuse requests and the third
  guarantees it never will.
````

## Self-review notes

Checked against the spec, and three things are recorded rather than silently resolved:

1. **The spec says the compiler refuses a bare `ESTABLISHED`.** It refuses a *missing* attribution, because `Verdict::Established(BackedBy)` cannot be constructed without one. It cannot refuse an *empty* one at compile time without more machinery than this is worth, so `BackedBy::new` is fallible and `an_established_verdict_cannot_name_nothing` pins it. The spec slightly overstated; the plan implements the honest version.

2. **`transit::differential::run_payload` is host-dependent.** It discovers decoder runtimes on the machine it runs on, which the spec did not capture. Task 4 handles it by naming missing runtimes in the finding's reason, because otherwise the same record would audit differently on two machines with no indication why. A *lack* of divergence is the weaker direction and the note matters most there.

3. **No repository carries tags**, so `rev` pins commit SHAs rather than the tags the spec assumed. Tagging the three dependencies would be an improvement to make before this ships, and would make the pins legible.
